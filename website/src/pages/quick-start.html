Delimited

For this example the file is delimited by a comma and has a header line:

Id,Name,Balance,Joined 1732,Juan Perez,435.00,2002-05-11 554,Pedro Gomez,12342.30,2004-02-06 112,"Politti, Ramiro",0.00,2000-02-01 924,Pablo Ramirez,3321.30,2002-11-24

1. The mapping class

Fields are read in declaration order. Use [FieldOrder(n)] when you want the order to be explicit.

using ModernLibs.FileHelpers; [DelimitedRecord(",")] [IgnoreFirst(1)] public sealed class Customer { public int Id; [FieldQuoted('"', QuoteMode.OptionalForBoth)] public string Name = ""; public decimal Balance; [FieldConverter(ConverterKind.Date, "yyyy-MM-dd")] public DateTime Joined; }

2. An engine to read and write

var engine = new FileHelperEngine(); // To read: the result is an array of Customer. // The skipped header line is kept in engine.HeaderText. Customer[] customers = engine.ReadFile("customers.csv"); // To write: HeaderText is written back first. engine.WriteFile("customers-copy.csv", customers);

3. Use the array

foreach (Customer c in customers) Console.WriteLine($"{c.Id}: {c.Name} owes {c.Balance}, joined {c.Joined:dd/MM/yy}");

Fixed length

Here every field has a fixed width, the kind of file a mainframe or a COBOL program writes:

000042John Smith 0001234.50 000043Mary Jones 0000980.00 000044Ramiro Politti 0000000.00

1. The mapping class

Each field declares its width. [FieldAlign] says how a value is padded when written, and [FieldTrim] what is removed when read.

using ModernLibs.FileHelpers; [FixedLengthRecord] public sealed class Employee { [FieldFixedLength(6)] [FieldAlign(AlignMode.Right, '0')] public int Id; [FieldFixedLength(20)] [FieldTrim(TrimMode.Right)] public string Name = ""; [FieldFixedLength(10)] [FieldAlign(AlignMode.Right, '0')] public decimal Salary; }

2. An engine to read and write

var engine = new FileHelperEngine(); Employee[] staff = engine.ReadFile("staff.txt"); // Writes the same layout back: zero-filled numbers, padded names. engine.WriteFile("staff-copy.txt", staff);

3. Use the array

foreach (Employee e in staff) Console.WriteLine($"{e.Id}: {e.Name} earns {e.Salary}");

[FixedLengthRecord(FixedMode.AllowLessChars)] and the other FixedMode values control how lines that are shorter or longer than the layout are handled. See the example.

Record by record

ReadFile returns the whole file as an array. For large files, read one record at a time instead. The record class is the same as above.

The FileHelpers 3.x pull loop

using var reader = new FileHelperAsyncEngine(); reader.BeginReadFile("customers.csv"); while (reader.ReadNext() is { } customer) { Console.WriteLine(customer.Name); }

Writing works the same way:

using var writer = new FileHelperAsyncEngine(); writer.BeginWriteFile("out.csv"); foreach (Customer c in LoadCustomers()) writer.WriteNext(c);

Async streams and callbacks New in 4.x

var engine = new FileHelperEngine(); // IAsyncEnumerable, with cancellation await foreach (Customer c in engine.ReadAsync("customers.csv", cancellationToken)) { Process(c); } // A callback per record; returns the number of records, allocates no array int count = engine.ReadFile("customers.csv", c => Process(c));
