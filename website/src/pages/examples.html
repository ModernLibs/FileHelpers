Quick start

Read a delimited file

10248|VINET|04071996|32.38 10249|TOMSP|05071996|11.61 10250|HANAR|08071996|65.83 [DelimitedRecord("|")] public sealed class Order { public int OrderId; public string CustomerId = ""; [FieldConverter(ConverterKind.Date, "ddMMyyyy")] public DateTime OrderDate; public decimal Freight; } var engine = new FileHelperEngine(); Order[] orders = engine.ReadFile("orders.txt"); foreach (Order order in orders) Console.WriteLine($"{order.OrderId} {order.CustomerId} {order.OrderDate:d} {order.Freight}");

Write a delimited file

var orders = new List { new() { OrderId = 1, CustomerId = "AIRG", OrderDate = new DateTime(2026, 3, 5), Freight = 82.43m }, new() { OrderId = 2, CustomerId = "JSYV", OrderDate = new DateTime(2026, 3, 6), Freight = 12.22m }, }; var engine = new FileHelperEngine(); engine.WriteFile("orders-out.txt", orders); // or get the text, or add to an existing file string text = engine.WriteString(orders); engine.AppendToFile("orders-out.txt", orders); 1|AIRG|05032026|82.43 2|JSYV|06032026|12.22

Read a fixed-length file

The kind of layout a COBOL program writes: no separators, every field at a known position.

01010 Alfreds Futterkiste 13122005 12399 Ana Trujillo Emparedados 23012000 00011 Antonio Moreno Taqueria 21042001 [FixedLengthRecord] public sealed class Customer { [FieldFixedLength(5)] public int Id; [FieldFixedLength(30)] [FieldTrim(TrimMode.Both)] public string Name = ""; [FieldFixedLength(8)] [FieldConverter(ConverterKind.Date, "ddMMyyyy")] public DateTime AddedDate; } var engine = new FileHelperEngine(); Customer[] customers = engine.ReadFile("customers.txt");

Write a fixed-length file

[FieldAlign] decides the side a value is padded on and the padding character.

[FixedLengthRecord] public sealed class Payment { [FieldFixedLength(8)] [FieldAlign(AlignMode.Right, '0')] public int Account; [FieldFixedLength(12)] [FieldAlign(AlignMode.Right, '0')] public decimal Amount; [FieldFixedLength(10)] public string Reference = ""; } var engine = new FileHelperEngine(); string text = engine.WriteString(new[] { new Payment { Account = 4711, Amount = 1250.00m, Reference = "INV-2031" }, }); 00004711000001250.00INV-2031

Read or write record by record

Use FileHelperAsyncEngine<T> for the 3.x pull loop. Despite the name it is synchronous: “async” means “not all at once”.

using var engine = new FileHelperAsyncEngine(); engine.BeginReadFile("customers.txt"); while (engine.ReadNext() is { } customer) { Console.WriteLine(customer.Name); } engine.Close(); engine.BeginWriteFile("customers-out.txt"); engine.WriteNext(new Customer { Id = 7, Name = "Around the Horn", AddedDate = DateTime.Today });

In 4.x you can also stream with await foreach or a callback:

var engine = new FileHelperEngine(); await foreach (Customer customer in engine.ReadAsync("customers.txt", cancellationToken)) Console.WriteLine(customer.Name); int count = engine.ReadFile("customers.txt", customer => Console.WriteLine(customer.Name));

Auto-properties

Properties work like fields. Records, positional records and required members do too.

[DelimitedRecord("|")] public sealed class Order { public int OrderId { get; set; } public required string CustomerId { get; init; } public decimal Freight { get; set; } } [DelimitedRecord("|")] public sealed record OrderLine(int OrderId, string Product, int Quantity);

Missing values

With nullable types

An empty field for a nullable value type reads as null.

10248|VINET||32.38 10249|TOMSP|05071996| [DelimitedRecord("|")] public sealed class Order { public int OrderId; public string CustomerId = ""; [FieldConverter(ConverterKind.Date, "ddMMyyyy")] public DateTime? OrderDate; public decimal? Freight; }

With [FieldNullValue]

Or keep the type non-nullable and name the value to use. The value must be a constant of the field type.

[DelimitedRecord("|")] public sealed class Order { public int OrderId; public string CustomerId = ""; [FieldNullValue(0)] public int Quantity; [FieldNullValue(0.0)] public double Discount; }

Different from 3.x: [FieldNullValue(typeof(DateTime), "2000-01-01")] is not available, because a DateTime cannot be an attribute constant. Declare the field as DateTime? and substitute the default in your code. Without either, an empty value-type field raises NullValueNotFoundException.

Attributes

[FieldTrim]

Mostly for fixed-length records, where short values are padded with spaces.

[FixedLengthRecord] public sealed class Customer { [FieldFixedLength(5)] public int Id; [FieldFixedLength(30)] [FieldTrim(TrimMode.Both)] // " Alfreds Futterkiste " -> "Alfreds Futterkiste" public string Name = ""; [FieldFixedLength(12)] [FieldTrim(TrimMode.Left)] public string City = ""; }

[FieldOrder]

Fields are mapped in declaration order. [FieldOrder] makes the order explicit, which helps with partial classes and inheritance. Use it on every mapped field or on none (MLFH024).

[DelimitedRecord("|")] public sealed class Order { [FieldOrder(20)] public string CustomerId = ""; [FieldOrder(10)] public int OrderId; // first column [FieldOrder(30)] public decimal Freight; }

FixedMode.AllowLessChars

By default every line of a fixed-length file must have exactly the declared length. FixedMode relaxes that when some lines are cut short or carry extra characters.

01010 Alfreds Futterkiste 13122005 12399 Ana Trujillo Emparedados [FixedLengthRecord(FixedMode.AllowLessChars)] public sealed class Customer { [FieldFixedLength(5)] public int Id; [FieldFixedLength(30)] [FieldTrim(TrimMode.Both)] public string Name = ""; [FieldFixedLength(8)] [FieldConverter(ConverterKind.Date, "ddMMyyyy")] public DateTime? AddedDate; }

The other values are ExactLength (default), AllowMoreChars and AllowVariableLength.

Converters

Enums

Enum fields are read by name, ignoring case, and written by name. No converter is needed.

ALFKI|Alfreds Futterkiste|SalesRepresentative ANATR|Ana Trujillo Emparedados|Owner public enum CustomerTitle { Owner, SalesRepresentative, MarketingManager } [DelimitedRecord("|")] public sealed class Customer { public string Id = ""; public string Name = ""; public CustomerTitle Title; }

A custom converter

Derive from ConverterBase, as in 3.x. It now lives in ModernLibs.FileHelpers.Converters. Here an amount is stored without its decimal point: 0001234 means 12.34.

using System.Globalization; using ModernLibs.FileHelpers.Converters; public sealed class ImpliedDecimalConverter : ConverterBase { public override object? StringToField(string from) => decimal.Parse(from, CultureInfo.InvariantCulture) / 100m; public override string? FieldToString(object? from) => ((decimal)from! * 100m).ToString("0", CultureInfo.InvariantCulture); } [FixedLengthRecord] public sealed class Payment { [FieldFixedLength(8)] public int Account; [FieldFixedLength(7)] [FieldAlign(AlignMode.Right, '0')] [FieldConverter(typeof(ImpliedDecimalConverter))] public decimal Amount; }

Converters can take arguments, which must be strings: [FieldConverter(typeof(TextBoolConverter), "ja", "nein")] calls a constructor with two string parameters. The generated code calls the constructor directly; there is no reflection.

A span converter New in 4.x

ISpanConverter<T> parses from a span and formats into a span, so no intermediate string is allocated.

using ModernLibs.FileHelpers.Converters; public sealed class IsoDateOnlyConverter : ISpanConverter { private static readonly DateOnlyConverter Inner = new("yyyy-MM-dd"); public bool TryParse(ReadOnlySpan span, out DateOnly value) => Inner.TryParse(span, out value); public bool TryFormat(DateOnly value, Span destination, out int charsWritten) => Inner.TryFormat(value, destination, out charsWritten); } [DelimitedRecord(",")] public sealed class Shipment { [FieldConverter(typeof(IsoDateOnlyConverter))] public DateOnly ShippedOn; }

Events and notification

INotifyRead<T>

Implement the interface on the record and it is told about its own reading. Use it to skip lines or to finish a record after its fields are filled.

[DelimitedRecord("|")] public sealed class Order : INotifyRead { public int OrderId; public string CustomerId = ""; public decimal Freight; public void BeforeRead(BeforeReadEventArgs e) { if (e.RecordLine.StartsWith("TOTAL")) e.SkipThisRecord = true; } public void AfterRead(AfterReadEventArgs e) { if (Freight < 0) e.SkipThisRecord = true; } }

INotifyWrite<T>

[DelimitedRecord("|")] public sealed class Order : INotifyWrite { public int OrderId; public string CustomerId = ""; public decimal Freight; public void BeforeWrite(BeforeWriteEventArgs e) { if (Freight == 0) e.SkipThisRecord = true; // do not write free shipments } public void AfterWrite(AfterWriteEventArgs e) { e.RecordLine = e.RecordLine.ToUpperInvariant(); // change the line that is written } }

Before/after read events

The same hooks as events on the engine, when the logic does not belong in the record.

var engine = new FileHelperEngine(); engine.BeforeReadRecord += (sender, e) => { if (e.RecordLine.StartsWith("#")) e.SkipThisRecord = true; if (e.RecordLine.StartsWith("END")) e.StopReading = true; // new in 4.x }; engine.AfterReadRecord += (sender, e) => { if (e.Record.Freight > 1000) Console.WriteLine($"Line {e.LineNumber}: unusually high freight"); }; Order[] orders = engine.ReadFile("orders.txt");

Before/after write events

var engine = new FileHelperEngine(); engine.BeforeWriteRecord += (sender, e) => { if (e.Record.CustomerId.Length == 0) e.SkipThisRecord = true; }; engine.AfterWriteRecord += (sender, e) => { Console.WriteLine($"{e.RecordNumber}: {e.RecordLine}"); }; engine.Progress += (sender, e) => Console.WriteLine($"{e.CurrentRecord} of {e.TotalRecords}"); engine.WriteFile("orders-out.txt", orders);

Different from 3.x: handlers are (object sender, XxxEventArgs<T> e). Lambdas compile unchanged; named handler methods need their first parameter changed from EngineBase to object.

Error handling

ErrorMode.ThrowException

The default. The first bad record stops the read with an exception that says where.

var engine = new FileHelperEngine(); // ErrorMode.ThrowException try { engine.ReadFile("orders.txt"); } catch (ConvertException ex) { Console.WriteLine($"Line {ex.LineNumber}, field {ex.FieldName}: '{ex.FieldStringValue}' is not a {ex.FieldType.Name}"); } catch (FileHelpersException ex) // base class: wrong field count, bad quoting, ... { Console.WriteLine(ex.Message); }

ErrorMode.IgnoreAndContinue

Bad records are skipped silently. Use it only when losing lines is acceptable.

var engine = new FileHelperEngine { ErrorMode = ErrorMode.IgnoreAndContinue }; Order[] good = engine.ReadFile("orders.txt");

ErrorMode.SaveAndContinue

Bad records are skipped and collected, so you can report them after the good ones are processed.

var engine = new FileHelperEngine { ErrorMode = ErrorMode.SaveAndContinue }; Order[] good = engine.ReadFile("orders.txt"); foreach (ErrorInfo error in engine.ErrorManager.Errors) { Console.WriteLine($"Line {error.LineNumber}, field {error.FieldName}: {error.ExceptionInfo?.Message}"); Console.WriteLine(error.RecordString); } if (engine.ErrorManager.Errors.Count > 0) engine.ErrorManager.SaveErrors("orders.errors.txt");

Advanced

Multi-record processing

One file, several layouts. Each record type gets a selector that says whether a line belongs to it; lines that match no selector are skipped.

ORD|10248|VINET LIN|10248|Queso Cabrales|12 LIN|10248|Singaporean Hokkien Fried Mee|10 ORD|10249|TOMSP [DelimitedRecord("|")] public sealed class Order { public string Kind = ""; public int OrderId; public string CustomerId = ""; } [DelimitedRecord("|")] public sealed class OrderLine { public string Kind = ""; public int OrderId; public string Product = ""; public int Quantity; } var engine = new MultiRecordEngine( MultiRecordType.For(line => line.StartsWith("ORD")), MultiRecordType.For(line => line.StartsWith("LIN"))); object[] records = engine.ReadFile("mixed.txt"); foreach (object record in records) { switch (record) { case Order order: Console.WriteLine($"Order {order.OrderId}"); break; case OrderLine line: Console.WriteLine($" {line.Quantity} x {line.Product}"); break; } }

Different from 3.x: there is no RecordTypeSelector returning a Type. The selector receives a ReadOnlySpan<char>; call line.ToString() if you need string-only methods.

Multiple delimiters

[FieldDelimiter] sets the delimiter that follows one field.

[DelimitedRecord(",")] public sealed class Reading { public int SensorId; [FieldDelimiter("|")] public string Unit = ""; // 17,celsius|21.5 public double Value; }

To write the same data with a different delimiter, declare a second record type and project: tabEngine.WriteFile(path, rows.Select(r => new ReadingTab { ... })).

Dynamic engine options Not in 4.x

In 3.x, engine.Options could change the delimiter, IgnoreFirst or field lengths at run time. Here the layout is compiled into the generated parser, so it cannot change after the build. Declare one record type per layout; a shared interface or base class keeps the rest of your code unaware of the difference.

Smart format detector Not in 4.x

SmartFormatDetector guessed a layout from sample files and produced a run-time class. It depends on run-time code generation and is not included. Declare the layout; for CSV files with no known schema, use a CSV-first library.

Struct records without allocations New in 4.x

A struct whose fields are all value types can be read through a callback or a streaming method without any heap allocation per record.

[DelimitedRecord(",")] public record struct Trade { public long Id; public decimal Price; public int Quantity; } var engine = new FileHelperEngine(); decimal notional = 0; int count = engine.ReadFile("trades.csv", trade => notional += trade.Price * trade.Quantity);

Parallel reads New in 4.x

For large inputs that fit in memory. The result is the same as a sequential read: the same records in the same order, the same errors and line numbers.

Order[] orders = engine.ParallelReadFile("orders.txt");

Records with quoted fields are read sequentially unless multiline values are turned off for them. See parallel reads.

Master/detail

With a common selector

When the master lines can be recognised by how they begin, end or what they contain.

ORD|10248|VINET LIN|10248|Queso Cabrales|12 LIN|10248|Mozzarella di Giovanni|5 ORD|10249|TOMSP LIN|10249|Tofu|9 var engine = new MasterDetailEngine(CommonSelectorMode.MasterIfBegins, "ORD"); MasterDetails[] groups = engine.ReadFile("orders.txt"); foreach (var group in groups) { Console.WriteLine($"Order {group.Master.OrderId}: {group.Details.Count} lines"); foreach (OrderLine line in group.Details) Console.WriteLine($" {line.Quantity} x {line.Product}"); }

With a custom selector

Return what each line is: a master, a detail, or something to skip.

var engine = new MasterDetailEngine(line => line.StartsWith("ORD") ? RecordAction.Master : line.StartsWith("LIN") ? RecordAction.Detail : RecordAction.Skip); MasterDetails[] groups = engine.ReadFile("orders.txt");

Different from 3.x: the enum CommonSelector is now CommonSelectorMode, the selector is passed to the constructor, and Details is an IReadOnlyList<TDetail> (use Count, not Length).

Sorting and transforms

FileHelpers 3.x shipped helper engines for sorting, converting and comparing files. They are not included in 4.x, because LINQ and the streaming reads do the same work in a few lines.

Sort a file BigFileSorter not in 4.x

var engine = new FileHelperEngine(); Order[] orders = engine.ReadFile("orders.txt"); engine.WriteFile("orders-sorted.txt", orders.OrderBy(o => o.CustomerId).ThenBy(o => o.OrderId));

For files that do not fit in memory, use an external sort tool, or read in chunks, sort each and merge.

Convert one format to another FileTransformEngine not in 4.x

Read with one engine, project, write with another. ReadSync streams, so the file is never fully in memory.

var source = new FileHelperEngine(); // the fixed-length record from above var target = new FileHelperEngine(); // a [DelimitedRecord(",")] with the same members using var reader = new StreamReader("customers.txt"); target.WriteFile("customers.csv", source.ReadSync(reader).Select(c => new CustomerCsv { Id = c.Id, Name = c.Name, AddedDate = c.AddedDate, }));

Compare two files FileDiffEngine not in 4.x

[DelimitedRecord("|")] public sealed record StockLine(string Sku, int Quantity); // records compare by value var engine = new FileHelperEngine(); StockLine[] before = engine.ReadFile("monday.txt"); StockLine[] after = engine.ReadFile("tuesday.txt"); IEnumerable added = after.Except(before); IEnumerable removed = before.Except(after);
