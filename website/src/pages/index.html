Flat files, read as typed records.

ModernLibs.FileHelpers reads and writes fixed-length and delimited text files (CSV, TSV, pipe) for .NET 10. You describe a record with attributes, the FileHelpers 3.x way; a source generator writes the parser at compile time.

Install dotnet add package ModernLibs.FileHelpers

Quick startComing from 3.x

One line, one record

Parsed

000042Id 6John Smith··········Name 200001234.50Salary 10

You write

[FixedLengthRecord]
public sealed class Employee
{
    [FieldFixedLength(6)]
    [FieldAlign(AlignMode.Right, '0')]
    public int Id;
    [FieldFixedLength(20)]
    [FieldTrim(TrimMode.Right)]
    public string Name = "";
    [FieldFixedLength(10)]
    [FieldAlign(AlignMode.Right, '0')]
    public decimal Salary;
}

You get

Employee
{
    Id     = 42,
    Name   = "John Smith",
    Salary = 1234.50m
}

The parsing code is generated when you build. Nothing is discovered by reflection at run time, so the same record works under trimming and PublishAot.

01 · Who needs it

Almost every system still trades in text files.

Bank statements, mainframe extracts, carrier manifests, ERP exports, the CSV somebody mails every Monday. The formats are old and they are not going away. This library is an easy and reliable way to read and write them as ordinary .NET objects.

  1. Imports and exports between systemsfixed-width and delimited, both directions
  2. COBOL and mainframe outputpadded, zero-filled, column-positioned
  3. Log and report parsingcomment lines, headers, footers, conditional records
  4. Data warehouse loadsstreaming, callbacks, parallel reads
  5. Format conversionread one layout, project, write another

02 · Two layouts

Describe the record. The engine does the rest.

Delimited

Id,Name,Balance,Joined 1732,"Perez, Juan",435.00,2002-05-11 554,Pedro Gomez,12342.30,2004-02-06 [DelimitedRecord(",")] [IgnoreFirst(1)] public sealed class Customer { public int Id; [FieldQuoted] public string Name = ""; public decimal Balance; [FieldConverter(ConverterKind.Date, "yyyy-MM-dd")] public DateTime Joined; } var engine = new FileHelperEngine(); Customer[] customers = engine.ReadFile("customers.csv");

Fixed length

000042John Smith 0001234.50 000043Mary Jones 0000980.00 [FixedLengthRecord] public sealed class Employee { [FieldFixedLength(6)] [FieldAlign(AlignMode.Right, '0')] public int Id; [FieldFixedLength(20)] [FieldTrim(TrimMode.Right)] public string Name = ""; [FieldFixedLength(10)] [FieldAlign(AlignMode.Right, '0')] public decimal Salary; } var engine = new FileHelperEngine(); Employee[] staff = engine.ReadFile("staff.txt"); engine.WriteFile("staff-copy.txt", staff);

03 · Features

The FileHelpers API, rebuilt on a source generator.

  • Easy to use

    A class, a few attributes, one engine call. See the examples.

  • Converters included

    Numbers, dates, booleans, Guid, enums and their nullable forms, with per-field culture. Write your own when you need to.

  • Events

    Before and after every record read or written, plus progress. Skip, rewrite or stop.

  • No reflection

    3.x generated code at run time. This generates it at build time: lines are sliced as spans and parsed in place.

  • Native AOT and trimming

    Built with IsAotCompatible and IsTrimmable. Publish with PublishAot=true.

  • Three error modes

    Throw, skip silently, or save and continue and read the error list afterwards.

  • Compile-time checks

    A missing field length is a build error, not a production incident. 29 diagnostics.

  • Records and structs

    Classes, structs, record and record struct, positional records, required members.

  • Record by record

    ReadAsync, ReadSync, callbacks and the 3.x pull loop. Large files stay out of memory.

  • Multi-record files

    Several record types in one file, each with its own selector. Example.

  • Master/detail

    Group detail lines under their master line while reading. Example.

  • Open source

    MIT licensed, free in any kind of project, no runtime dependencies. Source on GitHub.
