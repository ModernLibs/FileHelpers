NuGet

The package is ModernLibs.FileHelpers on nuget.org.

dotnet add package ModernLibs.FileHelpers

Or search for ModernLibs.FileHelpers in the NuGet package manager of your IDE.

Target frameworknet10.0The library targets .NET 10 only.

Runtime dependenciesNoneThe generator ships in the package as an analyzer.

Check that it works

Add a record type and read one line. If this builds and prints a name, the generator is running.

using ModernLibs.FileHelpers; var engine = new FileHelperEngine(); Customer[] customers = engine.ReadString("1,Ada Lovelace,120.50\r\n"); Console.WriteLine(customers[0].Name); // Ada Lovelace [DelimitedRecord(",")] public sealed class Customer { public int Id; public string Name = ""; public decimal Balance; }

If you get InvalidOperationException: No IRecordDescriptor<T> registered, the record type was not processed by the generator. Check that it has [DelimitedRecord] or [FixedLengthRecord] and that the build shows no MLFH errors. See troubleshooting.

Native AOT and trimming

All parsing and formatting code is generated at compile time. The library uses no reflection, Expression compilation or DynamicMethod, and is built with IsAotCompatible and IsTrimmable, so the trim and AOT analyzers check it on every build. Applications that use it can publish with:

true

Versions

4.x is a ground-up reimplementation that follows FileHelpers 3.x, so its major version continues after 3.x. Versions 4.0.0 to 4.7.0 were development milestones, published only as source releases on GitHub. 4.8.0 is the first release on NuGet. From 4.8.0 on, the package follows Semantic Versioning.

The changelog lists every release. This site describes {{VERSION}}.
