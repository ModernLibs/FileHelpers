# Step 0 filter file for benchmarks/tools/round.sh (T12). One benchmark glob per line:
#
#   <group> <pairs> <glob>
#
# <group>  the report table the results go into (round-report.py): read25, quoted, read-other, fixed, write, async,
#          exception, control, component, prototype; several comma-separated (async,exception) put the results in
#          each of those tables from one ab.py run
# <pairs>  the A/B pairs of round.sh that run the glob, comma-separated ("all" means every pair):
#          free-gains   pkg-net10 -> pkg-net11                     4.9.1 on .NET 10 against .NET 11
#          sdk-net10    pkg-net10 -> control-net10                 compiler and SDK effect, .NET 10
#          sdk-net11    pkg-net11 -> control-net11-ra-on           compiler and SDK effect, .NET 11
#          ra-control   control-net11-ra-off -> control-net11-ra-on  runtime async on the 4.9.1 source
#          v410-net10   pkg-net10 -> net10                         4.10 build against the package, .NET 10
#          v410-net11   pkg-net11 -> net11-ra-on                   the same on .NET 11
#          ra           net11-ra-off -> net11-ra-on                runtime async (D6)
#          runtime-410  net10 -> net11-ra-on                       the 4.10 build on .NET 10 against .NET 11
#          Native AOT harness (T47, ab.py --aot; group aot only, and group aot runs in these pairs only):
#          aot-v410-net10         aot/pkg-net10 -> aot/net10          4.9.1 package against 4.10, .NET 10
#          aot-v410-net11         aot/pkg-net11 -> aot/net11-ra-on    the same on .NET 11, runtime async on
#          aot-v410-net11-ra-off  aot/pkg-net11 -> aot/net11-ra-off   the same on .NET 11, runtime async off
#          aot-ra                 aot/net11-ra-off -> aot/net11-ra-on runtime async under AOT (a synchronous read: A/A)
# <glob>   a BenchmarkDotNet --filter glob, passed to ab.py as it stands. Each line is one ab.py run per pair, so
#          the methods one glob selects are interleaved with each other (the gates compare methods of one run).
#          For group aot, a glob over the AOT harness's scenarios (ab.py AOT_SCENARIOS).
#
# A glob that selects nothing in one of the two builds of a pair is skipped and reported as "not run" (for example a
# benchmark of a 4.10 API in a pair with a 4.9.1 build). Lines starting with # and blank lines are ignored.
# The methods and their Rows are listed in BENCHMARKS.md ("What is measured").
